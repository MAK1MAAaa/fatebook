每章主线分为4或6条任务链，可自由选择接受的委托；链内逐场解锁。可选挑战允许返回地区，主线不要求重复刷资源。已完成委托只保留标题、地点和完成标记，不再提供复习入口。阶段交接明确提醒未完成的本章可选挑战会留在过去。

144场遭遇的“敌方配置＋战场条件＋目标＋时限”组合均不同。后续章节常见两敌与三敌；32种普通对手有不同防御、连击、削弱、燃烧、再生、手牌干扰或仪式轮转。14个关键对手在半血时改变行动模式。龙神相关战斗为克制的撤离演练，不将玩家普通牌组描述为胜过原作龙神。

第一章8场非致命对练提示依次覆盖点牌目标、格挡、牌堆循环、半血换招、状态、援助条件、撤离与组牌。十回合救援要求及时击退阻截者；护送目标有独立生命，迷宫任务链包含反再生准备与守护者；决战仪式可压至0守过3回合，或击破核心，值达到8为战败。

## 界面信息层级（2026-10-09）

地区行动分为委托、人生选择、地图。首次开局优先基础教学；委托按主线、挑战、已完成切换，直接显示进度、目标、场地修正与操作。章节进度和未完成选择计数始终可见。

人生选择一次展示一个事件，直接显示两句必要背景，长文才收起；选项标签、具体影响与不可回退提示不折叠。永久死亡仍通过独立的二次确认对话框触发。战斗保留敌方意图、胜利目标、生命、状态及牌效；敌方预告考虑前排新施加的易伤和燃烧退场，不消耗随机数或修改战局。

组牌按基础卡 ID 合并普通与强化版，副本仍使用各自 UID；数量增减优先加入强化／取下普通，具体副本可在详情管理。完整图鉴有96种卡牌，按费用、流派、机制与拥有状态检索；实际牌效用正式引擎计算，获得条件依据导师、商店、事件和候选奖励。桌面双栏、手机视图切换，底部保存栏保留。年表使用章节与记录类型切换，每条仅一个详情层。阅读正文16px，触控按钮至少44px。

浅色面板正文和次级文字分别采用深棕 #3f3528、#66543a；浅色按钮有独立配色，禁用状态用底色和虚线标识，卡牌效果、费用和已完成记录不降低整体透明度。卡面统一固定为五个区域：费用与流派、插图、双行标题、完整效果、关键词。桌面高度282px，700px及以下高度270px；收藏、商店、手牌、奖励、牌堆和普通／强化详情共用规则。数量与获取条件属于卡面外的独立区域。96张卡最多两条机械效果、两个关键词，全部显示；风味说明移至详情，奖励详情仅供查看，不能修改副本。

立绘清单共67项，覆盖全部战斗角色、同伴、固定人物及自建种族的童年／青年外观；同一人物作为敌人或同伴时复用。原创同人和原创 IF 图片随应用加载，使用透明 WebP 大图／缩略图，失败时回退 SVG。开发生成工具不参与运行。

本次保持剧情、卡牌数量、真实战斗结算和存档格式，继续沿用2.0.0剧情版本。新增纯展示接口 CatalogFilters/CardGroup/PortraitDefinition/EnemyIntentForecast，不写入存档；保存失败时模态内可重试待写入结果，不再次执行动作。

## 身份与时间

五种身份各保留8个专属经历；同一NPC不能同时作为玩家和同伴。固定人物出生年遵循原资料：鲁迪与希露菲407、艾莉丝405、洛琪希373。前两章按各自出生后5／9岁，第三章起不早于417；后续422、427、429、441。年表不倒退。

出生地区随出身适配。教学路线使用当地对练、护卫和支援形式参与共同事件；任务战斗包含原创演习，无需声称每个人物亲身经历同一原著旅程。流派和技艺仍要学习，属性资质不直接创造特殊身份或能力。

## 重试与存档

每场种子由已保存人生种子与遭遇编号生成，洗牌使用可保存的确定性随机状态。洗牌前按卡牌与实体编号规范化牌组；仅更换编辑顺序不会重抽开局。原构筑重试恢复相同起点；换构筑可以改变策略，不反复抽新随机种子。普通战败不改人生状态；重试不收费，也不回退已完成任务。首胜奖励领取记录独立，已完成任务不提供再次挑战入口。

`resolveAction(previous, action, expectedRevision)` 是统一纯函数入口。成功动作增加版本号，过期版本和封存人生拒绝结算。Provider同步占用提交标志，排他锁内重新读取并重放动作核对，存储写入成功才发布状态。失败队列保存已算出的结果及原动作，重试仅提交同一结果。

战局保存种子、随机状态、回合、生命、护盾、状态、各牌堆、敌方意图、援助冷却及本场应急包。最近战局日志最多14条；完结战斗仅保存紧凑结果，不积累所有出牌日志。旧格式键隔离只读，不自动迁移。

18类旧结局保留：10类生存在七章完成后由已满足方向收束，隐退始终可选；8类死亡仅限对应章节，由明确不可逆按钮与二次确认触发。洛琪希疾病死亡只适用于洛琪希身份。
