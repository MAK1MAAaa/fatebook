# 《无职转生》世界观资料与游戏改编依据

## 研究口径

世界观研究使用 Exa，按地理社会、力量种族、人物时间线三个方向累计检索100条结果（是检索结果数量，不代表100条独立的一手证据）。核心内容交叉核对作者 Web 原作、作者《古龙的昔话》与 KADOKAWA/MF Books、动画官方人物资料。资料于2026年10月2日整理。

本游戏不是对原作段落的复制。所有选项、六维面板、点数、数值奖励、原创人物与替代结局都是原创 IF。原作提供人物身份、世界规则和时代背景。故事中的书籍、传闻或人物当时的解释未必等于最终真相。

轻小说正篇26卷，Web 原作章节与书卷不是相同编号；[官方书籍资料](https://promo.kadokawa.co.jp/mfbooks/title/mushoku/)与[作者目录](https://ncode.syosetu.com/n9669bk/)分别保留。官网随动画更新变化，因此百科直接标“基础世界观”或“小说后期”，不依赖某季播出范围。

## 力量体系与种族

魔术与剑术都使用初、中、上、圣、王、帝、神七阶，但分别按系别、流派记录。无咏唱是一种特殊控制方式；鲁迪的巨大魔力与幼年训练、特殊体质相关，不能成为所有角色加点后的自动收益。剑神流重先手与攻击，水神流重防守反击，北神流重临场应变与环境利用。

拉普拉斯因子的不同表现不能捆绑为统一“绿发、巨大魔力、不会斗气”的套餐。高属性也不能改变固定人物的先天限制或自动获得神子特征。首版固定人物只保留已有身份，技艺通过训练事件习得。

米格路德族寿命约两百年、外貌长期年轻，同族有特殊交流能力，洛琪希却无法使用。瑞杰路德所属的斯佩路德族有额头感知宝石，同时面对社会污名。游戏不把族群写成天然恶人，而是通过行为和兑现约定建立信任。长耳族和兽族的精确寿命本轮没有足够一手交叉证据，因此不写固定寿命数值；长寿角色以事业交接收束，不强制按鲁迪寿命死亡。

来源：[魔术教本](https://ncode.syosetu.com/n9669bk/4/)、[剑术说明](https://ncode.syosetu.com/n9669bk/6/)、[龙神说明](https://ncode.syosetu.com/n9669bk/181/)、[米格路德相关叙事](https://ncode.syosetu.com/n9669bk/25/)。

## 后期真相与不可误用的设定

- 普通治疗不能成为通用复活。龙神救回鲁迪是极特殊的事件，不能据此让每个死亡结局复生。[龙神遭遇](https://ncode.syosetu.com/n9669bk/66/)、[迷宫后的失去](https://ncode.syosetu.com/n9669bk/138/)
- 人神建议包含操纵，人物关于未发生未来的解释不能自动当成作者事实。[七星的假说](https://ncode.syosetu.com/n9669bk/172/)
- 龙神的两百年循环有条件与代价，玩家不能用游戏读档冒充这项能力。[龙神的真相](https://ncode.syosetu.com/n9669bk/204/)
- 鲁迪并非拉普拉斯本人。正篇结束时人神仍存在，后继者的未来仍有变数。[原作最终话](https://ncode.syosetu.com/n9669bk/285/)
- 转移灾难根源涉及后期召唤与未来因果，不能说成由人神随意制造。[原作尾声](https://ncode.syosetu.com/n9669bk/286/)

## 资料冲突处理

MF特设人物页曾出现基列奴称号文本异常，与动画官方、原作的“剑王”冲突。该处采用交叉一致的“剑王”。魔术教本中先给出角色所读的“总量天生固定”说法，同章后续训练又挑战了这一说法，不能只引用前半段锁死魔力成长。

百科展示精炼原著事实并附链接；剧情节点引用来源用于说明背景，不意味着原创选择、奖励与结局属于原作。

## 2.0卡牌RPG的事实与原创IF边界

2.0继续使用本文的原作地图、年代、技艺阶位和人物限制。七章战斗、96张卡牌的名称与效果、装备数值、敌方意图、圣级导师课程、演习目标和免费重试都是游戏设计，不是原著新增事实。属性加成不会赋予无咏唱、斗气、念话或龙神循环；洛琪希仍不能使用米格路德念话。战斗治疗只在进行中的战局恢复生命，不复活剧情死亡者。

山道龙神遭遇使用存活撤离演练目标；帮助龙神不等于玩家获得其能力。教学／留守角色可通过当地演习和支援任务参与事件，不将统一关卡结构当作人物的真实原著履历。迷宫无牺牲救援与额外人生结局仍明确属于原创IF。

2.0结局条件、内容配额与战斗因果见 [玩法设计](rpg-design.md)，引擎见证与验证限度见 [验证记录](rpg-verification.md)。
