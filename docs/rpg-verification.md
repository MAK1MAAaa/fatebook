## 2026-10-13：卡牌音效与战斗反馈增强

增强纸卡飞入、150ms后的命中冲击环、短促局部回震、大字真实伤害和击破收束。完全格挡只显示蓝盾吸收，不显示伤害0、不触发受伤回震；纯增益只作用于主角。意图、生命、格挡及操作保持独立位置，连续施放仍只显示最新相关文字。减少动画关闭飞入、旋转、缩放与回震，保留220ms静态反馈、240ms清理；短反馈命中音也改为即时触发。

音频激活、音量与静音设计参考[MDN Web Audio最佳实践](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)。正式战场只显示开关和音量；开发验收页额外显示真实设备状态及未结束声部数量，支持手动检查清理，不将计划音符数冒充实际播放数量。
