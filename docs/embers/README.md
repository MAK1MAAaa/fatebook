# 余烬来信项目规划

《余烬来信》是基于 main 分支玩法结构重新设计的独立原创地图 RPG。唯一开发路线为 Windows 上的 Godot 4 稳定标准版＋Rust，通过 GDExtension 接入：Godot 提供可视化编辑和表现，Rust 承担玩法与领域状态。当前目录提供游戏设定、剧情任务、系统规格、架构与开发交接资料，供之后建立正式游戏工程使用。

## 已确定的方向

- 独立原创世界，固定女性主角林恩与固定同伴；不保留原作人物、专名和立绘。
- 七章覆盖八岁至四十岁；黑暗幻想与生存压力来自资源、责任和选择后果。
- 正交地图探索、侧视指令回合战斗、最多四名出战成员。
- 当前进度内的剧情后果不可逆；允许读取较早手动存档，普通战败可以重试。
- Godot 场景与 Rust 核心分工明确；GDScript 只承担展示和输入，业务规则不维护两份。
- 先完成纯 Rust 规则切片和引擎桥接，再制作 60–90 分钟的独立裁切试玩，随后扩展七章。

## 技术路线

| 模块 | 主要职责 |
| --- | --- |
| Godot 工程 | TileMapLayer 地图、角色碰撞、Control 菜单、动画、音频与可视化编排 |
| `embers-core` | 纯 Rust 战斗、成长、资源、剧情、任务、结局与持久状态 |
| `embers-godot` | GDExtension、GameSession、主线程信号、内容加载与 SaveRepository |
| `embers-tools` | 内容 JSON 合并与引用整理，未来的内容检查和发布目录工具 |

不再保留 RPG Maker 的主路线、备选路线、数据库数值槽位、公共事件或两插件设计。迁移依据是[引用的版本比较讨论](chatgpt-conversation://6ace6546-8ce8-83ea-acb1-3746280d29d8)中“传统回合制 JRPG、Rust 编写玩法并保留可视化编辑”的需求。现有 2D 正交画面和内容规模不因技术选型增加 HD-2D 或 3D 制作范围。

## 内容基线

| 项目 | 正式版规划量 | 说明 |
| --- | ---: | --- |
| 人生章节 | 7 | 年龄 8、15、18、23、28、33、40 |
| 可玩地图 | 40 | 各章 6、5、7、7、5、5、5；阶段变化复用原地图 |
| 主线战斗 | 42 | 每章 6 场 |
| 可选战斗 | 14 | 每章 2 场 |
| 关键对决 | 14 | 包含在 42 场主线内，不另加 |
| 地区支线 | 14 | 每章 2 个；可选战斗可附属于这些任务 |
| 同伴个人任务 | 15 | 五名同伴各 3 个 |
| 基础技能 | 48 | 六类技艺各 8 个 |
| 同伴协作技能 | 5 | 玩家技艺合计 53 个；救援等属于领域任务动作 |
| 装备 | 30 | 武器、防具、饰品各 10 件 |
| 世界收束 | 3 个完整方案、2 个降级结果 | 不等于五条完整独立主线 |
| 事业收束 | 10 | 从已满足条件的方向选择，隐退始终可选 |
| 悲剧终局 | 8 | 主角死亡结果，不计普通战败 |
| 存档槽位 | 5 手动、1 自动 | 试玩存档与正式版隔离 |

这些数字是制作预算与设计约束，不代表已经生产相应内容。正式版时长 12–16 小时、试玩 60–90 分钟均为设计目标，需未来实际游玩记录确定。
