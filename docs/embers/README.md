# 余烬来信项目规划

《余烬来信》是基于 main 分支玩法结构重新设计的独立原创地图 RPG。开发主路线为 Windows 上的 RPG Maker MZ，Godot 为备选。当前目录提供游戏设定、剧情任务、系统规格与开发交接资料，供之后建立正式游戏工程使用。

## 已确定的方向

- 独立原创世界，固定女性主角林恩与固定同伴；不保留原作人物、专名和立绘。
- 七章覆盖八岁至四十岁；黑暗幻想与生存压力来自资源、责任和选择后果。
- 正交地图探索、侧视指令回合战斗、最多四名出战成员。
- 当前进度内的剧情后果不可逆；允许读取较早手动存档，普通战败可以重试。
- 先制作 60–90 分钟的独立裁切试玩，再扩展七章；不并行制作两个引擎版本。

## 内容基线

| 项目 | 正式版规划量 | 说明 |
| --- | ---: | --- |
| 人生章节 | 7 | 年龄 8、15、18、23、28、33、40 |
| 可玩地图 | 40 | 各章 6、5、7、7、5、5、5；阶段变化复用原地图 |
| 主线战斗 | 42 | 每章 6 场 |
| 可选战斗 | 14 | 每章 2 场 |
| 关键对决 | 14 | 包含在 42 场主线内，不另加 |
| 地区支线 | 14 | 每章 2 个；可选战斗可附属于这些任务 |
| 同伴个人任务 | 15 | 五名同伴各 3 个 |
| 基础技能 | 48 | 六类技艺各 8 个 |
| 同伴协作技能 | 5 | 技能定义合计 53 个 |
| 装备 | 30 | 武器、防具、饰品各 10 件 |
| 世界收束 | 3 个完整方案、2 个降级结果 | 不等于五条完整独立主线 |
| 事业收束 | 10 | 从已满足条件的方向选择，隐退始终可选 |
| 悲剧终局 | 8 | 主角死亡结果，不计普通战败 |
| 存档槽位 | 5 手动、1 自动 | 试玩存档与正式版隔离 |

这些数字是制作预算与设计约束，不代表已经生产相应内容。正式版时长 12–16 小时、试玩 60–90 分钟均为设计目标，需未来实际游玩记录确定。
