# 余烬来信游戏设定

《余烬来信》是一款独立原创的黑暗幻想 RPG：固定主角林恩从童年成长至中年，在道路失联、家园受损与设施军事化之间，决定怎样救人、核对真相，并把仍可运转的世界交给下一代。传统地图探索和回合战斗承担冒险，通信、调查与人物任务承担长期因果。

项目在 Windows 上使用 Godot 4 稳定标准版与 Rust 开发；Godot 承担可视化场景、地图、界面和演出，Rust 通过 `gdext` / GDExtension 承担游戏规则。技术边界与调用约定以 [Godot + Rust 架构](godot-rust-architecture.md)为唯一合同。

## 一 游戏定位

| 项目 | 设定基线 |
| --- | --- |
| 项目工作名 | 余烬来信；英文工程名 EmbersLetter |
| 主要受众 | 喜欢人物成长、回合策略和有后果选择的单机 RPG 玩家 |
| 主要平台 | Windows 离线单机，简体中文 |
| 开发路线 | Godot 4 稳定标准版 + Rust，使用 `gdext` 通过 GDExtension 接入 |
| 画面 | 48×48 地图格、俯视正交探索、侧视回合战斗、手绘对话头像 |
| 主角与队伍 | 固定女性主角林恩，五名固定可同行角色，最多四人出战 |
| 叙事跨度 | 八岁至四十岁，章间跳时，章内不设置实时年历 |
| 正式版体验目标 | 首次通关 12–16 小时，不靠重复刷取延长 |
| 首次开发目标 | 60–90 分钟独立裁切试玩，验证叙事与系统取舍后扩展 |

玩家获得的主要体验是：在已知风险下行动，看到准备如何改变救援结果；与同伴在价值冲突中继续合作；最后决定自己的生活与公共事业如何结束。

### 游戏的四个支点

1. **选择有实际回声。** 早年学会的语言、约好的地址、留下的笔记，应在后来的通路、救援和核验中派上用场。
2. **实力不能替代准备。** 角色等级使战斗更从容，但不能凭等级复活死者、补写遗失证词或替代撤离路线。
3. **同伴拥有自己的责任。** 同伴不会只在主角需要时出现；他们会质疑计划、承担工作，也会拒绝某些命令。
4. **结局包含交接。** 最后需要回答谁接手道路、诊所、资料和设施，战斗胜利本身不是全部成果。

### 内容边界

首发采用共享主线与局部任务分支，不制作多主角独立长篇。不加入开放世界、联网、即时战斗、随机生成地下城、恋爱攻略系统、完整城镇经营或全语音。人物亲密关系可以体现在对白和后日谈中，但不作为与主线并列的独立系统。

## 二 从 main 继承的设计经验

main 的现行游戏已经提供七章人生路线、卡牌构筑、身份经历与多结局。新项目保留结构经验，重新定义原创内容。

| 现有内容 | 延续方式 | 必须重做的部分 |
| --- | --- | --- |
| 七章成长 | 保留根源、学艺、断裂、重建、真相、棋局、传承 | 年代、地理、人物经历及章节场景 |
| 语言和通信 | 改为苇泽语、驿站地址与民间接应网络 | 所有原作文化与种族指向 |
| 迷宫调查与反再生准备 | 改为旧井污染设施和再生守卫 | 怪物来源、救援目标及研究结论 |
| 被排斥者援助 | 改为核对苇泽共同体遭受的指控 | 具体群体历史、证据与人物弧线 |
| 首胜奖励与免费重试 | 保留，服务不刷取的任务推进 | 多人指令战斗与战前快照 |
| 事业结局 | 保留家庭、教学、研究、重建等方向 | 完整条件、文本及世界结果组合 |
| 人生封存 | 改为当前进度中的不可逆后果 | 允许读旧手动档的本地存档体系 |
| 卡牌特效与音效 | 作为反馈参考 | 不搬用抽牌、卡面、三行动力及原作立绘 |

现有规则组合生成的 144 场遭遇是战术参考，不被视为 144 个已经完成编剧和关卡制作的原创章节。正式版按 56 场战斗重新编排。

## 三 世界与基础设施

### 衡原

衡原是大陆上一片连通的城镇与山地地区。故事不把所有世界历史纳入可玩地图，舞台限定在一条主要贸易走廊、相邻湿地与调度核心覆盖区。

城市富裕与乡村安全依赖同一套设施，却拥有不同的话语权。中心城区能够决定维护优先级，边境聚落常被要求提供矿料、劳力和土地。

### 路灯网

路灯网不是单纯照明，也不提供任意瞬间传送。它由道路灯塔、驿站共鸣器、地下调节井与中央灯枢组成，有三项功能：

- 稳定聚落周边的共鸣异常，降低野兽侵扰、火灾和污染暴发的风险。
- 在驿站之间传送容量有限的短消息；实物信件、货物与完整档案仍需要运送。
- 调节部分地区的灌溉、储能和生产设施，让商路与城镇能够持续运行。

消息需要发信站、收信站、时间与操作员记录。共鸣器能够出错，也可以被改写；签名和原始纸本有价值，却不保证写信者没有撒谎。

通信不会随处可用。装置损坏、能源分配不足和封锁都能使一段道路失联。因此，地址副本、人工信使和约定的接应地点仍然重要。

### 断灯之夜

灯历 630 年，军事改造将边境调节设备串联为大规模封锁阵列。测试期间，长期透支的地下节点无法释放回流能量，发生连锁事故。

防护失效后，灰脊道路塌陷，河湾外围起火，旧井污染扩散，消息系统留下互相矛盾的时间记录。许多聚落没有消失，却被切断交通与援助。

灯务署公开归因于“地方破坏”。这一解释掩盖了维护削减、试验命令和关闭安全旁路的责任。苇泽共同体因为拒绝交出旧线路而成为指控对象。

事故改变了主角的生活，也为各势力提供了扩大控制的机会。玩家逐步发现：第一场灾难已经发生，第二场仍然可以阻止。

## 四 共鸣术与力量边界

共鸣术通过身体、媒介与环境之间的能量交换产生效果。专业术者通常需要手势、呼吸控制与刻印器具，技能训练是控制与安全知识的结合。

| 领域 | 世界解释 | 战斗用途 |
| --- | --- | --- |
| 焰术 | 集中热量、破坏受污染组织的再生结构 | 烧灼、持续压力、反再生 |
| 寒术 | 抽取局部热量、稳定液体和关节 | 削弱、迟滞、控制 |
| 岩术 | 通过矿质媒介固定结构与屏障 | 防护、破甲、稳定伤害 |
| 风术 | 改变局部压力和流向 | 加速、扰乱、撤离掩护 |
| 医术 | 借助人体共鸣促进止血与恢复 | 治疗、净化、持续伤势处理 |
| 武技 | 身体训练、器械和队形配合 | 攻击、护卫、反击与牵制 |

热量与压力的改变不能无限持续。战斗用 MP 表达施术负担；重大设施事故需要工程措施，不能用个人恢复 MP 解决。

医术无法复活已经死亡的人，也不能将长期污染一步清除。HP 归零表示战斗失能，能够在安全地点恢复；剧情死亡必须由叙事明确认定。

个人熟练度分入门、熟练、专精、导师四个教学阶段。它决定技能学习资格，不形成神级、帝级或血统自动赋能体系。不同角色可以掌握不同领域，但正式版不要求每个角色学满全部技艺。

研究者能够提出假说，假说要通过样本、独立复核和实际操作成为可靠方法。主角不会获得可保证真实的预言或读心能力。

## 五 地理与社会

### 主要地区

| 地区 | 地理与生活 | 故事功能 | 视觉特征 |
| --- | --- | --- | --- |
| 河湾镇 | 河谷耕地与支线驿站，识字者承担记录工作 | 家庭、早年承诺、重建后果 | 木桥、低矮仓房、纸窗与暖灯 |
| 白垣城 | 大型市场、行会、官署与军需仓库 | 学徒生活、认证与政治会谈 | 白灰墙、铜管、拥挤门廊 |
| 灰脊山道 | 矿区与必经运输道路，天气多变 | 灾后营地、护送、封锁与撤离 | 岩壁、废轨、帐篷与断塔 |
| 苇泽 | 湿地与支流航道，地方医疗和路线知识完善 | 排斥与信任、替代商路 | 高脚木屋、织席、小舟与薄雾 |
| 澄台学院 | 位于旧井上层的研究教学区 | 医疗、调查、技术伦理 | 石阶、测量架、玻璃与标本柜 |
| 旧井 | 地下调节通道和废弃试验区 | 污染、生物异常与救援 | 灯笼、积水、旧刻印与冷白结晶 |
| 中央灯枢 | 山地调度中心及连接前线 | 世界结果与职责交接 | 大型机械环、控制室、狭窄维护道 |

地区之间的长距离旅行使用路线选择与短事件，不靠几十张空地图模拟路程。涉及危险的旅行提前显示补给需求与绕路代价。

### 人群与文化

主要角色都是人类。差异来自地区、职业、语言与社会地位，不将能力、道德或责任绑定到种族。

通用语用于城镇交易与行会档案；苇泽语用于湿地导航、医药与地方叙事。技术刻印属于训练后的识读能力，不另设一个“神秘种族语言”。

苇泽语有实际用途：减少转译遗漏、理解危险地名、核对地方证言。不会让只学通用语的玩家无法通关；后续可请译者或完成学习任务，但成本更高。

### 经济与制度

钱币在玩家界面统一计价，世界中仍有借据、实物援助与地方信用。商队、安全通路与诊疗资源受到封锁和维护状态影响。

行会评级衡量任务履历与合作信用，不能证明角色掌握全部战术。公告可能出错，因此高评级不自动取消风险。

重建资金存在“公开用途”和“附带条件”的区别。玩家可以接受紧急援助，但需要在后续公开、监督或偿付任务中处理代价。

## 六 势力与冲突

| 势力 | 正当需求 | 危险做法 | 可以合作的条件 |
| --- | --- | --- | --- |
| 灯务署 | 保持设施运转，避免失控停机 | 垄断档案，隐瞒事故，以保密排除监督 | 原始记录公开，技术交接，承认维护边界 |
| 边防议会 | 保护道路与城市，阻止武装袭击 | 将平民作为封锁成本，扩大军事改造 | 明确撤离通道、责任归属与独立复核 |
| 驿路互助会 | 恢复通信、运输和民间救援 | 牟利、伪造履历、出售行程信息 | 可信登记、透明结算和分散接应 |
| 苇泽共同体 | 保有土地、通行和自主管理权 | 内部有人拒绝任何外来协作，留下情报盲区 | 指控核验，地方代表参与，避免强制接管 |
| 澄台学院 | 保存知识、培养技术人员 | 默许研究被秘密挪用，以成果替代责任 | 独立复核、公开失败记录、限制军事用途 |

组织成员不是统一态度。任务中的具体行为会决定合作与对抗，玩家不能通过击倒所有成员获得理想秩序。

## 七 主角与家庭

### 林恩

林恩出生于灯历 612 年。她从小在驿站帮母亲整理来信，知道一张纸可能是一个家庭确认亲人是否活着的唯一办法。

她的初始长处是识字、路线记忆与注意细节。童年并非小型成年冒险者：战斗以训练、协作驱离和撤回安全范围为主，未成年人进入致命区域必须被叙事明确视为越界风险。

林恩害怕失联，容易把“获得更多证据”当作拖延决定的理由。玩家可以把她培养成护卫、术士或救护者，却不能改变她来自河湾镇和长期参与驿路工作的身份。

她在七章中要学会三件事：求证并不代表等待一切确定；承诺需要承认自己的能力边界；交接意味着允许后继者以不同方式继续工作。

### 何安

父亲何安是支线灯塔维护工。断灯之夜他进入地下旁路，帮助村民逃离后失踪。第四章的旧井救援将揭示他的去向。

断灯后，他与维护队留在旧井外围工营，因军事封锁失去对外交通与可靠通信。灯历 635 年，队伍从物资登记中核实其近况；他随后在当年的井下事故中被困。这里的五年失联不等于连续五年困在无法生存的井底。

他的生存由路线调查、反再生准备和救援时序决定，不由好感分数决定。完整准备能够救出他；其他结果可能只带回维护记录。即使生存，他也不能完全恢复原来的工作能力。

### 岚芹

母亲岚芹是驿站登记员。灾后腿部受伤，仍承担失散名单、口述证言和回信整理。

她会支持林恩追查，但反对为了亲人的线索随意征用别人的物资。后期她组织的新登记制度成为重建和民间撤离网络的基础。

家庭线不要求主角结婚或生育。共同家园可以由亲友、同伴与长期互助构成。

## 八 五名同行角色

### 赫岚

第二章加入，二十四岁，曾是边境护卫。善于盾卫与前排保护，不愿解释自己为什么离开军队。

他曾执行一份错误的封路命令，导致救援延误。他相信服从能够减少混乱，却逐渐承认自己选择相信哪份命令也构成责任。

个人弧线包括寻找命令副本、面对受害者、训练不盲从号令的后继者。他是主线最低队伍的保障，不设置永久死亡分支；负伤、关系断裂和失去个人事业结局仍是实际代价。

### 米娅

第二章加入，十八岁，地方医疗学徒。擅长净化和稳定伤势。她很少拒绝病人，却常把无法完成的诊疗承诺带回自己身上。

她曾未经完整说明取得污染样本，后来隐瞒了来源。研究确实改善救治，也让一些接触者没有及时接受检查。

她的任务从追补接触记录开始，最终建立能够承认错误、说明边界和分配转诊的诊疗机制。后期涉及她的牺牲必须与具体职责和已知风险有关。

### 赛洛

第三章加入，二十二岁，苇泽向导。控制、绕行和辨识环境是他的长处。

他被迫携带自证身份的文件，却厌恶被要求替整片湿地解释。他不愿每次伸出援手都以证明族群清白为前提。

个人弧线从找回通行证、核对被破坏的渡口记录，走向建立不依赖个人名声的共同通行协议。他不会因林恩替他作证就永久同意所有后续决定。

### 诺弥

第四章加入，二十五岁，澄台研究者。擅长共鸣输出、设施分析与器械调整。

她认为提供更好的工具就能减少伤亡，起初拒绝讨论工具的最终使用者。军事改造所用的稳定技术来自她所在团队。

她需要保全失败数据、接受独立复核、亲自参与危险停机，并写下使用限制。研究结局必须包含别人能够重复的方法，不能以天才灵光代替验证。

### 温德

第五章加入，三十五岁，旧信使与情报贩子。擅长侦察、寻找缺口和利用资源。

他曾出售行程和来信，间接暴露了证人。他认为所有消息迟早都会被买走，直到必须面对自己选择卖给谁的后果。

个人弧线要求恢复投递链、找到受损家庭、公开自己的交易记录。他的可靠性来源于实际交接，不是一次道歉。

### 人物关系安排

| 关系 | 主要冲突 | 可以形成的合作 |
| --- | --- | --- |
| 林恩与赫岚 | 求证与立即执行之间的摩擦 | 明确行动边界与撤退条件 |
| 林恩与米娅 | 是否可以为了救更多人隐瞒风险 | 共享诊疗信息，承认有限能力 |
| 赛洛与赫岚 | 封路者与被封路者的历史 | 共同制定可复核的通行程序 |
| 米娅与诺弥 | 治疗现场与实验数据不一致 | 共同追踪接触记录与反污染方法 |
| 温德与所有人 | 交易信息造成的不信任 | 用完整记录与实际保护重新获得合作 |

关系不用单一好感条概括。人物任务阶段、兑现承诺与当前冲突分别记录，影响对白和合作能力。

## 九 主要对手

### 维岑

灯务署总监。知道旧系统逐渐失效，认为必须集中资源才能避免全面崩溃。他承担部分真实维护工作，也继续掩盖为中心城区服务的透支。

他不会提供完全虚假的世界解释：突然关闭路灯网确实会伤害依赖设施的居民。但这一事实不能替代公开责任，也不能授权他继续安排没有同意的牺牲。

### 卡铎

边防统领。推动将调节设施改为区域封锁武器，认为一次无法公开的牺牲可以换取长期安全。

他需要道路、仓库和调度人员配合，不拥有脱离社会资源的神级力量。玩家可以切断他的执行条件，而不必把冲突写成两名最强者的决斗。

### 冲突的终点

揭露命令、停止执行、恢复设施和处理责任是不同工作。最终行动必须同时考虑平民撤离、控制权与实际维护者；单纯击败维岑或卡铎无法自动提供理想结局。

## 十 七章的情绪与时间

| 章节 | 年份与年龄 | 情绪重点 | 应当留下的改变 |
| --- | --- | --- | --- |
| 根源 | 620，八岁 | 熟悉生活中的不安与安全感 | 地址、语言、观察与第一项承诺 |
| 学艺 | 627，十五岁 | 离家与第一次承担责任 | 技艺、同行者、任务判断 |
| 断裂 | 630，十八岁 | 失散、恐惧与互相依赖 | 家庭去向、通行、信任与救援网络 |
| 重建 | 635，二十三岁 | 暂时安顿与未解决的伤 | 父亲命运、诊疗、研究与家园 |
| 真相 | 640，二十八岁 | 怀疑、求证与证人风险 | 事故责任、可公开证据和合作边界 |
| 棋局 | 645，三十三岁 | 妥协、承诺与权力的成本 | 监督、替代商路和联盟分工 |
| 传承 | 652，四十岁 | 疲惫、信任与职责交接 | 世界方案、后继者与个人收束 |

章间跳时用两到三个具体场景说明生活变化：谁接手了岗位、地区哪里恢复、仍有什么问题。年表标明跳跃，不能让玩家误以为几场任务就自然过去五年。

前期没有让成年同伴穿越时间提前出现。童年使用家人、当地教习与临时协助者；正式队伍在第二章开始形成。

## 十一 黑暗内容与选择呈现

黑暗气质由后果、失联与有限援助构成。伤亡可以严肃呈现，但不靠密集血腥镜头、突然处刑或反复羞辱角色制造刺激。

重大选择应提供四项信息：目前知道什么、谁会承担风险、有哪些替代行动、哪些结果无法在当前进度撤销。信息可以不完整，但不能隐藏已经被主角掌握的关键事实。

普通错误允许局部失败、追加成本或后续补救；明确越过致命边界才进入悲剧终局。玩家可以通过较早手动存档重选，不设置读档惩罚。

至少保留一项真正的安全出口：延期、绕路、缩小目标、申请帮助或选择较差但可生存的结果。安全出口可以让玩家失去机会，不能伪装成与冒险完全等价的收益。

对话选项不使用隐藏嘲讽或与措辞相反的结果。风险确认针对死亡和重大永久人物损失，不给每次普通调查弹出确认窗口。

## 十二 视觉与声音

### 视觉方向

基调为乡野幻想与早期工业设施。路灯是铜制器械、刻印媒介和维护管道的组合，不采用现代终端或网络机房外观。

| 元素 | 基准 |
| --- | --- |
| 地图与行走角色 | 像素风，48×48 地图格，统一人物脚点与遮挡规则 |
| 头像与关键插图 | 手绘，服装与像素角色保持一致 |
| 环境主色 | 灰绿、旧木褐、暗铜；避免整个游戏只能看到黑色 |
| 安全与通信 | 暖黄灯光，封蜡、纸本与清楚可读的标记 |
| 污染与设施异常 | 冷白与灰蓝、断续光，不用快速频闪 |
| 战斗反馈 | 伤害、防护、净化、目标损失分别有文字与形状提示 |

林恩采用儿童、青年、成年三阶段。成年阶段通过头像、服装、姿态与对白表现年龄，不为每章另做全套动作。五名同行角色各有加入期与后期两阶段。

40 张地图依靠故乡、城市、山路、湿地、学院、地下与核心七个素材族复用。每章使用少量专属物件表达变化，避免重复铺设完全相同的走廊。

### 声音方向

故乡主题强调轻微生活声与清楚的旋律，灾后版本保留同一动机但减少乐器。最终阶段将主题交给不同配器，表达继承而不是强行胜利。

试玩采用故乡、道路、危险区与战斗四首循环曲，加基础交互、共鸣、警报与环境声音。正式版规划十首循环曲和三段短收束音乐，具体素材交付由开发交接表管理。

不制作全语音。紧急情况通过声音、文字和视觉同时传达，静音玩家也能够理解任务目标。

### 菜单与日志

核心菜单为队伍、技能、装备、任务、人物、年表、地图与系统。任务页首先显示可执行目标，然后列可选准备与已知风险；设定长文可主动阅读，不作为每次推进的强制阅读门槛。

界面使用容器布局，保证键盘焦点、取消返回和鼠标点击都能完成相同操作。字体和信息不只靠颜色区分。菜单与战斗的详细输入规则见系统与数据规格。

## 十三 结局与传承

世界收束围绕分权接管、有限集中和紧急关闭三种完整方案。没有准备好相应技术、撤离或监督时会出现降级结果，而不是继续显示“完美胜利”。

林恩随后从满足条件的十项事业方向中选择一项作为自己的收束；隐退始终开放。其他已完成成果仍进入后日谈，不因选择隐退就删除已建成的诊所。

传承不等于必须让主角子女接班。学生、同事、当地维护者和其他独立组织均可成为后继者。后继者需要具备技能、职责与资源，不能只在结尾收到一件信物。

所有剧情条件、五类世界结果和八类悲剧触发以[章节剧情与任务](story-and-quests.md)为准。世界观不另行提供隐含的自动成功条件。

## 十四 制作阶段与可视化编辑

第一阶段冻结本设定与配套任务、系统表以及 Godot + Rust 架构合同；第二阶段在 Windows 新建 Godot 工程与 Rust 扩展，建立地图交互、指令回合战斗和存档的完整流程；第三阶段完成独立裁切试玩；随后扩展完整七章和正式素材。

Godot 的可视化编辑用于制作内容与呈现，不另建一份游戏规则状态：

| 工作 | 作者编辑位置 | 运行时职责 |
| --- | --- | --- |
| 地图与交互点 | `TileMapLayer` 地图、场景节点；交互节点在 Inspector 中配置稳定内容 ID | Godot 处理显示、移动与交互请求，Rust 判断出现条件与合法行动 |
| 人物与战斗演出 | `Sprite2D`、`AnimationPlayer`，队伍与敌方的 2D 场景 | Godot 播放 Rust 已结算的动作与结果，不从动画回调计算伤害或改写剧情事实 |
| 菜单与日志 | `Control` 容器、输入焦点与主题 | Godot 展示 Rust 提供的状态和可用选项，提交选择请求 |
| 剧情、任务与技能 | 外置 JSON 内容定义，使用稳定事件、任务、人物和技能 ID | Rust 解释条件、剧情行动 `StoryAction` 与战斗动作 `ActionKind`，结算剧情、战斗、数值、资源及存档领域状态 |

允许薄层 GDScript 连接输入、场景和演出；条件判断、奖励、人物生死、结局资格与战斗计算归 Rust 权威核心。场景中的过场与动画只能呈现已结算结果，不能通过自定义脚本直接改变任务事实。数据格式与桥接接口统一遵循架构文档，不在各剧情场景重复定义。

画面继续采用 48×48 正交地图、像素行走角色和最多四人侧视回合战斗。《星之海》与《歧路旅人》仅提供传统 JRPG 与像素演出的讨论参考；本方案不因此增加 3D 地图、全套 HD-2D 管线或额外内容配额。

试玩使用故乡的四张地图与学徒时期的山路、旧泵站两张地图。它是正式内容的重组展示，省略任务用明确叙事交代，不伪造正式版任务完成记录。试玩存档与正式版隔离。

本轮只交付详细规划，不将设定数量、游玩时长或技术方案写成已实现成果。数值是初始设计基线；之后在 Godot + Rust 工程中依据试玩结果调整，并同步更新系统规格。
