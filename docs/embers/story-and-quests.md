# 《余烬来信》剧情、任务与结局详细规划

> 文档状态：设计基线，尚未实现。供未来在 Windows 上使用 Godot 4 稳定标准版与 Rust（`gdext` / GDExtension）开发时编写剧情内容、地图场景与对话。本轮只整理规划，不安装开发资源，不执行游戏、构建或测试。
>
> 来源关系：沿用 main 的七章主题、语言与通信因果、反再生救援、任务目标、十种事业与八种悲剧的结构经验；重建世界、年代、人物、事件与条件。不保留原作专名、人物身份或一对一替名，不沿用旧项目 144 场遭遇和 138 个文字节点的配额。

## 1. 叙事约定与内容总量

### 1.1 核心表达

林恩从一名核对来信的孩子，成长为能够组织调查、救援与设施交接的人。她无法靠个人武力修复全部问题，必须决定如何分配有限援助，并承担公开真相后的责任。

黑暗感来自失联、资源分配、错误命令与基础设施依赖。每章必须同时保留日常关系、有效援助和能够改变的局部结果；不以连续虐待、无预警死亡或否定全部努力制造气氛。

- 主角为女性，固定姓名林恩，灯历 612 年出生，无转生、预言身份或独占世界级能力。
- 童年章的战斗均由成人组织或陪同，失败按训练/撤离处理，不让八岁孩子独自承担成人武装冲突。
- 主要事件是固定剧情，人物表达与解决方式随任务事实变化；没有统一善恶分、剧情随机死亡或高属性自动获知真相。
- 普通战斗 HP 归零是失能。剧情死亡、失踪和牺牲才会永久改变当前进度；玩家仍可读取较早手动存档。
- 林恩与赫岚构成后期主线保底队伍。赫岚不会在主线永久死亡；伤势与关系断裂可以改变协作、个人任务和后日谈。
- 其他同伴的永久损失只放在第六、七章明确告知风险的选择中，且主线另有可推进解法。

## 2. 世界规则与固定人物

### 2.1 路灯网的社会作用

衡原的路灯网同时负责道路防护、短消息通信与局部环境调节。设备、耗材、技术人员与调度资格都有限。中心城市获得稳定能源时，边境可能被迫减少防护；关闭危险设施可以阻止下一次事故，也会影响耕作和运输。

“断灯之夜”由长期透支、隐瞒维护事故和军事改造共同造成。前期人物可以误解为地方破坏，但旁白不得提前把传闻写成已证实事实。

共鸣术通过身体、介质与环境交换能量。个人施术不能替代大型设施；治疗不能复活死者；污染记录可能失真，需要独立材料核对。正常战斗的施法费用使用 MP，剧情的严重透支通过事件和持续伤势处理，不另造一套透支数值。

父亲何安是路灯维护工，断灯之夜失踪；母亲岚芹是驿站登记员，在安置行动中腿部受伤。岚芹活至最终章，持续参与登记与互助工作，拒绝被写成只等待救援的角色。何安在灾后随维护队留在封闭的旧井外围工营，交通与通信被军事封锁；不是连续被埋在井下五年。第四章先核实他近年的工作登记，再处理当前发生的下层事故：完整调查、反再生准备与实际保护可以救回他，准备不足且救援窗口耗尽时只能带回记录。第五章根据生死分为本人证词或工作遗稿，不能将死亡路线写成仍然在场。

固定辅助人物：导师廖澄负责驿路训练；研究员喻嘉参与旧井救援；证人洛砚保留调度副本；灯务署改革官桑宜提供受约束的制度合作；后继者安葵与嵇衡分别承接通信与维护工作。上述角色不占战斗队伍槽位。

### 2.3 对手与机构

- 灯务署总监维岑知道系统衰败，却以维持运行之名隐瞒事故和强制征用；第六章必须处理其控制资格，不必将其处决。
- 边防统领卡铎推动军事改造并销毁责任记录；第五、六章揭示的是具体命令链，而非把全部军人归为恶人。
- 驿路互助会组织民间通信与运输，拥有帮助人的能力，也存在出售消息和挪用资金者。
- 苇泽共同体提供语言、通路和地方医术；居民意见各异，不能作为奖励主角的统一族群。
- 澄台学院既有公开研究者，也有依赖保密资助的人。有效技术与受害经历不能自动让人物拥有全部真相。

## 4. 七章完整剧情路线

### 4.1 第一章：根源（灯历 620，林恩 8 岁）

**起：** 林恩在河湾驿站帮母亲抄写来信。家中保存着父亲的道路维护记录，但她尚不理解设备与登记的关联。第一场训练从读指令、保护同伴和主动防御开始。

**承：** 孩子在练场、集市与河堤之间学习劳动。苇泽货商的来信被误分，林恩可以核对语言、将信退回，或让成人代办。一次风暴使林缘野兽靠近镇内，成人组织儿童与居民撤离。

**转：** 林恩发现数封信件到达日期与登记册不一致。导师廖澄指出“记录可能有误”，不立即给出阴谋结论。玩家选择抄存副本、告知父母或暂时搁置；主线始终保留家人能够说明的基础事实。

**合：** 家庭完成一次公开的应急演练，林恩学会不把个人逞强当作救援。她决定是否维护固定通信地址、学习苇泽语、保留异常动物观察笔记。

**两场关键对决：** `c1-main-05` 协同驱赶演练，考查角色职责；`c1-main-06` 林缘撤离，考查在保护居民时合理攻击。两场均不造成儿童剧情死亡。

**主要选择：** `c1-choice-contact` 保留家庭通信地址；`c1-choice-language` 学习苇泽语或改学基础维护；`c1-choice-notes` 将动物异常记录留给驿站或仅保留个人记忆。拒绝通信不会惩罚所有亲人，仅影响灾后寻找副本的效率。

**章门槛：** 六场主线首胜/目标完成、家庭应急登记完成、培养意向记录。两条支线不影响离开。

**跳跃到 627 年：** 年表展示林恩持续读写、父亲维护工作、母亲登记职责；展示少年外观与家庭状况。未学习苇泽语时可以在第二章付出学习时间补修基础，不补发童年交流内容。

### 4.2 第二章：学艺（灯历 627，林恩 15 岁）

**起：** 林恩取得驿路学徒资格，选择护卫、术士或救护作为初始培养方向。赫岚负责路线安全，米娅负责基础医疗；玩家第一次安排三人分工。

**承：** 行会以委托级别衡量能力，却用过时记录低估山路危险。队伍处理护送、诊疗物资、货仓异常和旧设施巡查，逐渐发现某批共鸣介质去向不明。

**转：** 旧泵站出现异常蓄压。行会希望先维持运输，廖澄要求停止附近通行。玩家可以保留独立样本、提交被简化的报告或让成人暂管材料；选择影响后来证据的完整性。

**合：** 泵站运输事故发生。队伍争取救援窗口，并在事故后建立接应约定。林恩获得正式工作资格，赫岚与米娅决定继续同行；“委托完成”与“所有人获救”被明确区分。

**两场关键对决：** `c2-main-05` 护送资格考核；`c2-main-06` 旧泵站抢救。

**主要选择：** `c2-choice-sample` 保存原始样本并注明来源；`c2-choice-relay` 建立接应制度；`c2-choice-risk` 在事故中采用可靠绕行还是独自进入已经失稳的旁路。冒险旁路有直接死亡风险提示，可靠解法不要求隐藏属性。

**章门槛：** 六场主线完成，事故报告提交，三人合作条款确定。报告可以不完整，不能阻断主线。

**跳跃到 630 年：** 展示三年工作与通信状态，列出报告最终处理结果。断灯之夜不是林恩一次错误选项引起的，也不能因她一次正确报告完全避免。

### 4.3 第三章：断裂（灯历 630，林恩 18 岁）

**起：** 断灯之夜破坏道路防护和驿站。队伍先把母亲与邻里送入营地，父亲失联。焚毁驿站保留可以核对的痕迹，但不是回到童年场景重新领取奖励。

**承：** 营地补给不足，通行证由边防队控制。赛洛被指控破坏灯网；调查发现指控只有一份来源不明的告示。林恩可以支持公平核验、暂缓表态或接受现有程序。

**转：** 山道被封锁，救援与撤离不能同时无限推进。队伍选择先保护名单与诊疗物资，或先腾出通路。赛洛无论是否得到公开作证都会加入短期合作，但信任与后续居民支持不同。

**合：** 队伍把可撤离居民送到渡埠。父亲仍未找到；母亲选择留下做登记，林恩不必要求她退出工作。保存的名字、地址与失踪名单成为以后核验证人的起点。

**两场关键对决：** `c3-main-05` 营地夜袭防卫；`c3-main-06` 山道撤离。

**主要选择：** `c3-choice-permits` 公开通行证排序或换取自己队伍的优先权；`c3-choice-testimony` 为赛洛争取核验而不是直接宣告其无罪；`c3-choice-names` 保留遇难与失联名单；封锁和荒路的致命风险选择另有明确退出路线。

**章门槛：** 六场主线完成，队伍抵达渡埠，母亲去向与名单保管者记录。救援人数、物资状态可有差异。

**跳跃到 635 年：** 以营地登记、重建资助与三人来信表现五年生活；林恩在工作中积累技能，不通过一次自动升级获得全部术式。

### 4.4 第四章：重建（灯历 635，林恩 23 岁）

**起：** 安置街区恢复日常，但诊所与房屋仍不够。诺弥邀请队伍调查旧井，希望找到更安全的设施技术；学院要求先完成公开研究许可。

**承：** 研究员喻嘉发现旧井生物能够再生，物资登记也证实何安曾在被封锁的维护工营生活。玩家收集来源、试做烧灼与净化方案、安排撤离锚点。重建物资可以偏向诊疗或通路，两者都能继续剧情，回访内容不同。

**转：** 新发生的旧井下层事故使何安、喻嘉与工人被困。诺弥承认早期图纸曾提供给灯务署；她尚不知道最终用途。研究材料、退出锚点和队员分工决定救援结果，单纯高伤害不能代替准备。进入下层前明示缺项及其可能造成的救援损失。

**合：** 队伍救出被困者或带回遗物，确认旧井承担军事改造实验的调节功能。何安活着时需要休养并参与维护交班；死亡时岚芹获得明确材料与告别，不让失踪悬念继续拖延。研究成果公开保留，家园建设交给当地负责人，林恩不把重建成果视为个人所有。

**两场关键对决：** `c4-main-05` 再生守卫；`c4-main-06` 下层救援。

**主要选择：** `c4-choice-study` 完成反再生研究；`c4-choice-safety` 为救援留下退出锚点；`c4-choice-rebuild` 公开分配物资并安排后继维护者。缺少准备时仍能救出部分人员；何安与喻嘉若已死亡，不能通过后章研究补救复活。

**章门槛：** 六场主线完成，救援结果结算，至少一种重建方案落实，污染样本移交记录明确。

**跳跃到 640 年：** 诊所、街区与工地按结果更换事件。研究成果的署名、失去的人与污染患者留在年表中，不把五年空白写成所有问题自动解决。

### 4.5 第五章：真相（灯历 640，林恩 28 岁）

**起：** 队伍收到一封无法立即信任的警告。温德提供运输线索，承认自己曾交易来信情报；接受有监督的合作不等于原谅他。

**承：** 洛砚保留调度副本，货运账册记录改造材料。玩家分别核对人证、运输记录和设施图纸，逐步确认卡铎的军事改造与维岑的隐瞒。

**转：** 证人受到监视，隔离院隐瞒污染病例。队伍必须决定何时公开证据、先护送谁以及如何保全独立副本。何安活着时说明封闭工营的维护流程；死亡时工作遗稿留下同样可核验的设备编号，但缺少能在听证上回应的问题，不把文字材料当作替身。

**合：** 原始档案被带出，至少一份真实材料进入公共记录。完整证据可以说明责任链；缺失证人时仍能说明设施异常，不允许对白声称已证明全部命令。

**两场关键对决：** `c5-main-05` 证人转移；`c5-main-06` 档案封锁。

**主要选择：** `c5-choice-disclose` 公开已核实部分、先保护证人再公开或暂缓公开；`c5-choice-origin` 说明样本与账册来源；`c5-choice-patients` 接受医疗与隔离或带着明确重症风险继续行动。

**章门槛：** 六场主线完成，一份原始材料被安全存放，公开/暂缓状态明确，父亲消息完成核验。完整证据非必需。

**跳跃到 645 年：** 以公示、诉讼/听证进展、技术培训和城市通行变化表现五年。保护证人与公开证据各有现实成本，任何选择都不会让全社会立即一致。

### 4.6 第六章：棋局（灯历 645，林恩 33 岁）

**起：** 多城面临第二轮灯网衰败。桑宜邀请队伍提出改造方案；维岑要求把所有资料交回灯务署，卡铎要求以军事封锁维持供给。

**承：** 队伍争取替代商路、地方维护者与公开监督，必须写明谁出钱、谁能检查、谁能停止危险运行。援助带有条件，玩家不能同时答应互相排斥的控制权承诺。

**转：** 会谈遭袭，军方试图夺取调度站。赫岚面对曾经同僚，公开承认封锁命令造成的损失；其他人物是否愿意继续协作取决于实际保护与交接。

**合：** 调度站停止未经批准的军事指令。维岑被解除独占控制，或接受仅有形式的妥协；卡铎的控制链被切断，但基层撤防和设施衰败仍需处理。

**两场关键对决：** `c6-main-05` 会谈袭击；`c6-main-06` 调度站争夺。

**主要选择：** `c6-choice-aid` 援助条件的接受与公开；`c6-choice-oversight` 三方实际监督或集中托管；`c6-choice-transfer` 将操作权交给受训人员；后期同伴可以选择承担一项高风险断后任务，玩家必须获知替代方案。

**章门槛：** 六场主线完成，调度权结果结算，至少一条补给路线保持通行，灯枢行动队成立。监督或分权准备失败仍能进入最终章。

**跳跃到 652 年：** 七年维护并非静止等待。展示培训、老化、联盟履约与下一代；最终事故由设施寿命与残留改造共同触发。林恩年龄达到 40 岁，各同伴更新服饰与职位。

### 4.7 第七章：传承（灯历 652，林恩 40 岁）

**起：** 中央灯枢异常扩散，林恩必须交接日常工作后再出发。安葵和嵇衡已能承担通信与维护，是否具有独立决定权取决于以前的培养与交接。

**承：** 队伍完成平民转移、稳压与环廊防护。研究、商路和信任链转化为更可靠的退出条件；没有完整准备也保留撤离和结束主线的路径。

**转：** 中央灯枢不能无限持续旧式运行。玩家在进入最终操作前看到已成立的方案与欠缺条件：分权接管、有限集中、安全关闭，或代价更高的临时处理。

**合：** 最终战斗先解决失控设施与残余武装，再选择公共方案。战斗胜利不自动带来最优世界结果。幸存的林恩从已经完成的事业中选择后半生，最终一封信由后继者写给她。

**两场关键对决：** `c7-main-05` 灯枢控制核心；`c7-main-06` 残余武装与失控设施。

**主要选择：** `c7-choice-heirs` 实际交接或保留全部决定权；`c7-choice-civilians` 优先撤离安排；`c7-choice-world` 从已具备条件的世界方案中选择；`c7-choice-sacrifice` 只在明确缺少退出窗口时开放自愿殉难，与正常战败区分。

**章门槛：** 六场主线完成，操作后果已结算；主角幸存时开放事业选择，主角死亡时进入对应悲剧终局。

## 5. 主线战斗目录（42 场）

### 5.1 使用规则

- 每表第 05、06 场为本章关键对决，已经包含在六场主线中。
- “前置”是剧情阶段，不是属性门槛。若某种调查选择被放弃，用基础委托推进同一战斗；只有附加救援或奖励受影响。
- 回合时限是初稿目标；时限失败仅记任务结果或返回准备，不直接生成剧情死亡。悲剧另由明确事件选择结算。
- “后果”首先记任务事实；首胜经验、钱币和物品由系统规划统一配置，不在对白重复结算。
- 并行的中段任务可按任意顺序完成；第 05、06 场以章阶段收束，不允许绕过章门槛。

完整链提供可靠通信与撤离条件，帮助查明何安去向，但不能单独保证第四章救援，也不改变断灯之夜。补救以新的年份和责任人记入年表；若何安已经死亡，重建通信不能使其复活。

### 9.2 研究链

| 阶段 | 建立的事实 | 可见后果 | 错过后的补救 |
| --- | --- | --- | --- |
| c1 异常笔记 | `early-observation-kept` | c4 研究者发现再生现象并非突然出现 | c2 保存样本；c4 做额外公开观察，不补童年结识 |
| c2 样本出处 | `sample-origin-recorded` | c5 原始证据能确认材料运输，而非无来源传闻 | c4 对照设备编号与矿源；需更多事件成本 |
| c4 反再生研究＋退出锚点 | `anti-regeneration-study`、`rescue-exit-anchors` | 旧井救援获得完整窗口，有条件救回何安、喻嘉与工人 | 战中破修复节点保基本出口；何安或喻嘉已死不能重做救援改写 |
| c5 公开方法与病例 | `public-research-procedure` | 技术可由外部人员复核，减少个人隐瞒 | c6 对保留样本与记录做公开审查，只恢复技术可信度 |
| c7 实训试停 | `safe-shutdown-tested` | 安全关闭世界方案成立的一部分 | 人工旁通可结束主线，但形成代价更高的紧急处理 |

完整研究必须同时包括方法、材料出处和实际试行。诺弥技能等级高不能直接赋予安全停机事实。

### 9.3 信任链

| 阶段 | 建立的事实 | 可见后果 | 错过后的补救 |
| --- | --- | --- | --- |
| c1 苇泽语 | `reed-language-basic` | 对话可直接核对，不把翻译者当作可疑障碍 | c2 基础课程；c3 由赛洛翻译，成本和自主性不同 |
| c3 公平核验 | `guide-testimony-respected` | 居民愿意说明灯标，赛洛不是唯一担保人 | c4 向居民说明失误并归还扣留物资；功能可恢复，首次不公仍留在对白 |
| c3 安全水路 | `wetland-route-surveyed` | c5 账册与运输地点可独立比对 | c5 重新勘路，材料较晚到达；无法补回已错过的证人保护 |
| c5 公共通行条款 | `community-passage-agreed` | c6 有共同体参与的替代商路 | c6 从公开协商开始，承担修路与收费限制 |
| c6 替代供给线 | `alternative-supply-route-ready` | 分权接管有实际运力，紧急关闭有更好撤离条件 | c7 集中运输只保障基础出口，不伪造已形成的分权运力 |

信任来自承诺兑现与可核验行为；不会因为会说语言就自动解锁全部居民帮助，也不会因一人死亡让整个共同体永久敌对。

## 10. 世界、事业与悲剧结局

### 10.1 结局结算顺序

1. 普通战败先进入免费重试/准备，不结算人生终点。
2. 主角明确剧情死亡时，按当前场景进入对应悲剧终局，停止世界与事业选择；后日谈只说明已知后果，不替玩家补做最终决定。
3. 主角幸存且第七章主线完成时，评估世界方案。先展示已满足条件的三个理想方向，并逐项说明缺项。
4. 至少一个理想方向成立时，玩家从已满足方向中选择，准备充分也可以自愿选择界面已解释代价的保留/关闭处理；没有理想方向时，保留基本集中运行与代价更高的紧急关闭作为可结束主线的两条处理。
5. 世界结果确定后，展示已解锁的个人事业，由玩家选择一项；隐退幸存始终可选，不用隐藏优先级替玩家选事业。
6. 最后按人物生死、个人任务和公共事实组合后日谈，不为全部排列组合另造整章剧情。

所有世界方案至少能通过共享主线建立基础操作出口。准备不足影响安全程度、权力归属和后续成本，不产生“无结局可选”或必须回档的软锁。

### 10.2 世界结局（3 个理想方向＋2 个准备不足结果）

| ID／世界方向 | 明确解锁条件 | 结果与代价 |
| --- | --- | --- |
| `world-distributed` 分权接管 | c5 原始档案与至少一份独立运输/证词来源能相互核对；c6 替代供给线成立；地方维护者受训并取得真实操作权；援助账目公开 | 多地共同管理，军事独占被拆除；部分区域暂时停灯，初期维护变慢 |
| `world-supervised` 有限集中 | 军事改造证据公开；c6 灯务署、地方代表与民间运输者三方实质监督成立；危险操作有外部暂停权；c7 基础撤离完成 | 恢复较快，集中权力仍存在；后日谈保留监督是否持续的风险，不宣布永久政治胜利 |
| `world-safe-shutdown` 安全关闭 | 反再生与污染方法可公开复核；c7 可逆试停通过；受训维护者能独立操作；民间接应或替代运输支撑全部预定转移 | 避免继续透支与军事复用，损失部分设施、交通和耕作能力，转入长期重建 |
| `world-unchecked-central` 缺乏监督的集中接管 | 最终选择保留运行，但分权/监督条件没有对应成立，或玩家明确放弃已可行的公共约束 | 保住较多短期供给；独占结构延续，地方依赖加深。准备中的公开证据与撤离成果仍在后日谈起作用 |
| `world-disordered-shutdown` 失控关闭 | 最终选择关闭，但安全试停、独立维护或完整撤离中的任一必要条件不足 | 战术上阻止新军事指令，关闭过程造成更大停灯与迁徙；既有通路和医疗会减轻代价，不写为全部人死亡 |

世界优先级不是数值排行榜：所选方向满足其条件才生成对应理想结果。不同准备组合以补充段落表现，而不是把所有不足都写成相同灾难。玩家不能在选择集中托管后被系统自动改成分权，也不能靠最终多选按钮同时取得三个世界方向。

### 10.3 个人事业（10 个）

以下事业均须林恩幸存并完成第七章。每个方向的条件显示在年表/事业页，缺项可见；同伴死亡不会自动清除其此前已经移交的公共成果。

| ID／事业 | 解锁条件 | 收束内容 |
| --- | --- | --- |
| `life-home` 家园守望 | 母亲工作安排获尊重；第四章安置有公开份额；第七章返乡交接完成 | 留在家乡维护日常互助，何安的存活/死亡改变家庭片段，不把父亲救援设成此事业的唯一门槛 |
| `life-post` 驿路维护 | 接应制度成立；第五章新地址簿与独立副本制度完成；第七章通信交班 | 林恩巡检道路，安葵负责日常通信，失联者仍在记录中 |
| `life-medic` 医者 | 米娅第二、三个人任务完成或其公共成果已实际移交；无名病房规则落实；第七章医疗转运 | 建立不以身份拒诊的巡诊队，不声称所有患者都已治愈 |
| `life-teacher` 教育者 | 至少一套技能课程开放；安葵/嵇衡独立实训完成；不是仅保留主角个人笔记 | 学生能质疑教师并继续修正规程，知识不依赖林恩在场 |
| `life-craft` 技艺传承 | 赫岚三阶段完成，护卫规程移交；至少一次主线护送结果记录用于教学 | 建立兼顾撤离与保护的训练场，面对旧命令责任 |
| `life-research` 研究者 | 污染方法与来源公开可复核；诺弥前两阶段完成；试停或安全维护实训完成 | 持续研究与外部检查并存，保留无法复原的损失 |
| `life-rebuild` 故乡重建 | 房屋分配公开；地方维护岗位建立；最终转移和重建材料归属记录 | 将故乡建设交给居民共同决定，主角负责具体工作而非拥有城镇 |
| `life-mediator` 政治调停 | 三方实际监督或分权协议成立；援助条件公开；至少一次非战斗通路协商兑现 | 继续处理资源与权力冲突，没有一纸协议永久和平 |
| `life-traveler` 自由旅人 | 至少两地有安全接应；个人工作已经移交；最后出发地址登记 | 主角继续旅行且保持联系，不用消失来回避责任 |
| `life-retired` 隐退幸存 | 无额外条件，主线完成后始终可选 | 主角停止一线行动，活下来的价值不由事业完成数衡量 |

### 10.4 悲剧终局（8 个）

这些终局均由明确危险事件选择触发，不由普通战败、属性不足或随机判定触发。危险正文需说明潜在死亡、现有替代方案与不可逆结果；二次确认文案使用具体动作，不能只写“确定”。

| ID／终局 | 章节与触发情境 | 安全出口 | 记录内容 |
| --- | --- | --- | --- |
| `trag-child-boundary` 幼年越界 | c1 在成人明确禁止、已失稳的河堤闸内坚持独自进入 | 等待成人取回或放弃物品 | 孩子死亡与家庭后果；绝不奖励特殊能力 |
| `trag-reckless-commission` 失控委托 | c2 事故中选择已警告无法稳定的单人旁路 | 与赫岚/米娅使用共同救援路线 | 所谓更快捷径的后果；试玩唯一悲剧入口 |
| `trag-lost-road` 荒路失联 | c3 在无接应、明确无可用水源的荒路坚持单人远行 | 登记同行或较慢绕行 | 失联而非证实尸体时，后日谈明确“未找到”，但本局终止 |
| `trag-checkpoint-fire` 封锁枪火 | c3 明知封锁交火已开始仍独自冲入射界 | 申请核验或由向导走安全渡口 | 具体命令和目击，不给主角殉难自动带来政治胜利 |
| `trag-well-collapse` 旧井坍塌 | c4 无锚点且结构已失稳时明确拒绝撤离 | 带出能救的人，承认救援不完整 | 已救者与遗物状态保留；不能读成战斗计量失败自动死亡 |
| `trag-contamination` 污染恶化 | c5 已出现严重症状、诊所可治疗时反复明确拒绝处理并带病执行禁行任务 | 接受诊疗与隔离，由同伴转交材料 | 病情与制度问题共同呈现，不把患病本身当道德失败 |
| `trag-meeting-murder` 会谈刺杀 | c6 有明确袭击警告和护送可用时，坚持单独赴已暴露地点 | 改会址、核验信使或携带护送 | 真相和未完成协议保留；不自动假定刺杀解决所有冲突 |
| `trag-core-sacrifice` 灯枢殉难 | c7 退出窗口不足时，玩家明确选择由林恩留守完成手动切断 | 使用更慢退出并接受更大停灯/物资损失 | 仅结算当时已完成的公共成果，主角不再选择个人事业 |

同一事件只指向一个明确终局；不会同时给出“刺杀”“污染”并让隐藏条件决定显示哪一个。存档保留进入危险前的手动槽位，自动存档不覆盖手动存档。当前进度中的复活、撤销承诺或重新领取人物不提供。

## 11. 首个试玩的精确裁切

试玩是完整规划的选段，使用原地图、任务和战斗 ID，不新增第八章，也不将五场试玩战斗再计入正式版数量。

### 11.1 地图与战斗

| 类型 | 复用内容 |
| --- | --- |
| 六地图 | 家、河湾驿站、练场、集市（c1）；山路、旧泵站（c2） |
| 四场主线 | `c1-main-01`、`c1-main-02`、`c2-main-01`、`c2-main-06` |
| 一场关键对决 | 只计 `c2-main-06`，其余三场不标关键 |
| 一场可选战斗 | `c2-opt-01` 走失的驮兽 |
| 两个非战斗支线 | `c1-side-01` 没有地址的信，使用集市/渔人代取解法；`c2-side-01` 接应不是口头话，使用驿站回执和泵站等待点解法 |
| 十二技能 | 从正式版 48 基础技能中选择，覆盖攻击、防护、控制与恢复；具体 ID 与效果以系统规划的试玩技能表为准 |

裁切流程：童年家务与训练 → 通信选择 → 灯历 627 年学徒跳跃 → 山路三人护送 → 原始证据选择 → 可选驮兽 → 接应约定 → 泵站事故 → 两种救援收尾或单一悲剧。

全版第二章中段货仓、检疫和考核在试玩以短年表交代“已经发生的工作经历”，不建立正式存档中的任务完成事实。试玩使用独立开始/终点与 Rust 核心管理的 demo 流程状态，只在试玩上下文开放泵站任务；不据此允许正式版从第一课直达第六场。试玩存档不迁入正式版，避免跳过内容的状态污染。

### 11.2 三个可追踪选择

| 选择 | 选项与信息 | 试玩内后果 |
| --- | --- | --- |
| 通信 `c1-choice-contact` | 登记地址并保存回执；只口头说明；暂不联系。说明通信工作量，不用道德评价诱导 | 泵站是否有明确接应点、家人是否收到完整消息、事故后第一封信内容变化 |
| 证据 `c2-choice-sample` | 保存带来源样本；仅报告现象；将材料交行会。说明谁能日后核对 | 米娅识别污染的准备、事故报告可信度与结尾原始材料状态变化 |
| 风险 `c2-choice-risk` | 共同救援可通关；更慢绕行可保人但损失设备；单人旁路明确可能死亡 | 共同/绕行进入可玩救援；玩家坚持旁路并确认才进入悲剧 |

### 11.3 两个可玩救援结果

- **及时救援：** 接应与调查准备较完整，战斗中完成双组救援计量。两组人员都及时离开，设备损失，事故责任仍待核查。
- **延迟救援：** 准备较少或战术拖延，队伍先救出一组，另一组由增援接回并有人重伤；结尾明确其存活与治疗责任，不能模糊成额外隐藏死亡结局。
- **悲剧：** 单人进入失稳旁路，林恩死亡，试玩结束。此结果来自明确选择，不是救援战斗输掉后自动发生。

试玩结尾显示通信、证据和救援三条记录如何相连。主角不在试玩打倒世界级反派，世界与事业结局留给正式版。

## 12. 事件与对白编写交付规则

每个主线场景建立一个事件稿，至少包含：事件 ID、地图与出现阶段、人物在世/在队条件、进入正文、选项必要信息、事实变化、年表记录、退出位置和重复进入时的短文本。稿件使用稳定内容 ID，并交付为外置 JSON 事件定义；具体字段与调用形式以 [Godot + Rust 架构](godot-rust-architecture.md)为唯一合同。

Godot 场景里的交互节点在 Inspector 中引用内容 ID，不保存一套镜像剧情事实。出现条件、选项条件与剧情行动 `StoryAction` 由 Rust 核心解释和结算；战斗中的 `ActionKind` 另行定义攻击、防御、技能与任务动作。战斗、属性、资源、剧情及存档领域状态均由同一核心负责。编剧按已定义动作组织事件，不在场景脚本、动画轨道或对白控件中另写奖励、生死与结局判断。

可视化交付分两部分：`TileMapLayer` 地图与交互位置，及 `Sprite2D` / `AnimationPlayer` / `Control` 组成的角色、过场和界面。过场呈现 Rust 已确认的事件结果；需要玩家选择时向核心提交请求，再依据返回结果继续演出。薄层 GDScript 可以连接输入和演出，不承担业务判定。

每章正文按以下稿件包生产：

1. 章开场与上一章结果回顾。
2. 六场主线战斗的战前、目标说明、成功/任务不完整和战后文本。
3. 两场可选战斗与两条支线的解法、缺席和过期文本。
4. 当章同伴任务与在队/离队/死亡替换文本。
5. 三类重要准备的实际收益、补救成本和风险提示。
6. 章交接清单、年份跳跃、地区可见变化和回访短文本。

对白不机械复述状态数值。必要目标和危险必须在正文与任务页直接可见，不能只藏在物品风味说明里。证据不完整时使用“支持这一判断”“仍缺来源”而非“已经证实”；人物发言与全知事实分开写。

人物演出只制作有意义的差异：林恩儿童/青年/成年三阶段，同伴加入/后期两阶段；伤势通过有限头像、服饰和动作表达。不为每岁重画角色，不为每个结局组合制作新场景。

本文件为规划输入。未来实现时可据此制作外置内容定义、Godot 地图与演出场景，并接入 Rust 权威核心；本轮没有生成引擎工程、运行游戏或执行验证，所有时长、回合窗口与救援配额仍属于待制作的设计值。
