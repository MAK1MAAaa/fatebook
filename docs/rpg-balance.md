全七章：6 人物配置 × 4 构筑 × 4 种子 × 2 政策 × 2 规则 = 384 次。第一章另做 8 个种子，共 768 次；前 4 种子与七章实验重叠，不合并当作独立样本。固定随机人物为兽族／大森林／莉亚、零追加属性，并保留 randomized 标识，避开创建器的非种子 Math.random。

入门政策按可见攻击、防护、治疗优先级行动，固定前排目标，只训练两个熟悉流派；启发式政策观察实时牌效与敌方意图，考虑击杀、救援、仪式、抽牌、回能、异常与同伴，学习四个相关流派。两者均每三场／每章整理牌组、购置可负担且提升效果的装备、强化实际预设牌；启发式补充至多四张高评分副本。奖励入门取第一张、启发式取正式预设评分最高的一张。政策版本已固定，旧新比较不改变行为。

旧规则正式见证：144 / 144 遭遇、28 可选遭遇、18 / 18 结局；逐动作重放已有文件。新规则正式见证：144 / 144 遭遇、28 可选遭遇、18 / 18 结局。见证政策是覆盖证明，不计入配对完成率。

- 七章入门完成 77/96 → 96/96；即时收益启发式 92/96 → 81/96。新版有明确政策退化，不能宣称全面平衡改善。
- 新版配对样本实际进入 7 / 7 章；失败记录必须结合其遭遇目标阅读，通关样本的均值不代表所有人生完成全部内容。
- 构筑自由度与主线可达性由多个政策测量；自动化失败只证明该政策在该配置失败，不证明游戏不可通关。
- 所有章节战斗重建满生命及应急包；损血是该场受到的累计伤害，可以超过最大生命。旅费收入、装备、学习、购牌与强化分别记录，不能用最后余额替代经济流。
- 七件饰品在两套规则均无额外效果；政策避免重复购买等效饰品，因此这里主要测量首次可负担性，不能据此推断真人会否误购。
- 每回合 80 次动作、每战 100 回合是模拟保险上限；触发会标明 timeout，不将其归为已证明的无限循环。
- 奖励用途按领取的实体 UID 跟踪是否进入预设以及后续是否实际打出；最后一场奖励没有后续出场机会，天然压低使用率。
- 即时收益启发式的防守构筑完成 20/24 → 9/24；新版 15 次失败全部位于 c3-main-13。该构筑防御强，但限时救援的输出与手牌流转存在机会成本。
- 可重放实例 custom/guard/paired-01：第 11 回合救援超时，仍 258/258 生命、累计损血 0、出牌 15 次、援助 4 次。原政策只评估即时伤害／实际缺血／预计格挡需求，健康时不会打出无即时收益的保留牌；保留牌积累达到 10 张手牌上限后阻塞抽牌。失败包含明确政策局限，不能直接证明预设或规则结算有缺陷。
- 第一章入门两套规则均 192/192 完成，新版平均回合 5.94 → 4.74，平均损血 9.38 → 13.93。提速伴随更高损血，需人工判断是否符合教学体验。
- 新版七章入门最终旅费均值 6022，启发式 4165；其中启发式包含提前失败人生，不能直接比较经济富余。多数完整人生余额较高，后期购买压力可能偏低；详细支出和各构筑完整率在 JSON。
- 独立疏通政策敏感性实验（6配置×4种子×旧新，仅防守全章）：旧规则 15/24、新规则 20/24 完成。此实验保留主政策全部原始结果；只检验策略因素，不修改正式数值。

硬性检查：所有实战预设通过正式牌组校验；每次失败报告人物、构筑、种子、遭遇和 RNG；完整运行记录保存在 `docs/rpg-balance-runs.jsonl`，汇总／逐章指标／配对／失败位置在 `docs/rpg-balance.json`。启动器记录参与引擎与政策源码哈希，报告不使用运行耗时换算真人时长。Wilson 95% 区间仅作固定样本描述；同配置多种子的关联与自适应采购使其不能作为真人胜率或正式总体推断。

命令：

```sh
node scripts/simulate-rpg.mjs
node scripts/simulate-rpg.mjs --smoke
node scripts/simulate-rpg.mjs --trace --character=custom --style=balanced --seed=paired-01 --policy=heuristic --ruleset=2.1.0
```

完整模拟写报告；smoke 写独立文件并重复一个固定实例核对 action trace 哈希；trace 保存每个决策之前／之后状态、可用出牌／援助／治疗／结束回合的政策评分、所选动作及 RNG。地区采购动作也记录，候选集合为该政策当次考虑的动作。
