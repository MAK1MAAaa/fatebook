## 见证文件与时长

[ending-witnesses.json](ending-witnesses.json) 保存18种终局的完整角色配置和 `choiceIds` 顺序，无人工注入的事件或资源。测试读取此文件，逐步调用 `createGame` 与 `resolveChoice` 并核对结局和正文字符数。主动更新剧情后可重新生成：

```bash
GENERATE_ENDING_WITNESSES=1 node_modules/.bin/vitest run tests/ending-witnesses.test.ts
```

10条生存见证为53–60次决策，正文约16,985–19,166个非空白可见字符；包含身份补充及终局文字，排除按钮、结算说明、界面与年表。可选支线会增加次数，本次浏览器家庭路线为61次。

45–90分钟是内容与阅读体验目标，尚未经真实玩家完整阅读计时。不能用自动化选择的耗时证明这个目标。按每分钟约250–450个可见字符，并为每次选择预留思考时间，可形成该量级的体验；这个速度区间是估算假设。

没有实际持有手机进行 Safari／Chrome 真机测试；已完成浏览器屏宽验证与局域网HTTP检查。软键盘、安全区和减少动画的样式已实现，真机体验仍需后续反馈校准。
