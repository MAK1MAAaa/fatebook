# 命运之书 2.1 · 无职转生原创 IF 卡牌 RPG

中文纯前端游戏：创建角色 → 地区任务 → 学习与组牌 → 卡牌战斗 → 人生选择 → 多结局。包含完整原作剧透；卡牌、战斗数值和新增分支均为原创 IF 游戏设计。采用原创动漫立绘、SVG 与 CSS 界面素材，无账号、后端或运行时在线生成服务。

## 启动与手机访问

需要 Node.js 22.12+、npm。项目已在 Node.js 24 环境验证。

```bash
npm ci
npm run dev
```

打开 **http://localhost:6657/**。开发和预览统一绑定 `0.0.0.0:6657`，启用 `strictPort`，端口占用时直接报错。手机与电脑连接同一局域网，在手机访问 `http://电脑的局域网IP:6657/`；防火墙须允许该服务。手机和电脑浏览器的存档各自独立。

```bash
npm run lint
npm test
npm run build
npm run preview
```

构建产物在 `dist/`，使用 HashRouter。预览、开发和 Docker 容器不可同时占用 6657。

## 玩法

- 七个人生章节，116场主线遭遇、28场可选挑战、14场章节关键对决。任务链有前置遭遇；完成本章主线与人生事件后主动进入下一章，可选挑战无需刷取。
- 96张基础卡牌、32类普通敌人、14个关键对手、10名援助同伴、21件装备。战斗包含击退、护送、撤离、限时救援与仪式压制目标；所有遭遇具有不同的敌方组合、环境或目标。
- 一名主角与一名援助同伴对战1–3名敌人。每回合恢复3行动力、抽5张牌；普通手牌弃置，保留牌留下，消耗牌本场移除，抽牌堆用完洗入弃牌。全部攻击固定命中。
- 点手牌与敌人目标，再按“使用此牌”。敌方意图显示预计数值，同伴支援冷却3回合；不依赖拖动或悬停。
- 全部96张牌都有施放与结算特效：按魔术、剑术和身份区分符印，实际目标显示伤害、格挡吸收与状态，主角显示护盾、治疗、净化、抽牌和回能。强化与全体牌有额外反馈，最后一击播放完进入奖励；系统减少动画偏好显示短暂静态反馈。
- 初始牌组18张，正式构筑15–25张，同一卡牌最多3张。导师解锁技能牌，首胜与商店提供卡牌，工坊可一级强化、移除收藏及使用四种构筑预设。
- 战败可以无限免费重试，恢复本场生命、应急包和牌堆。相同牌组与相同种子保持相同洗牌；换牌组、装备、同伴可以改变战术。已完成任务和首胜奖励不会回退或重复发放。
- 18种结局：10种生存收束、8种剧情死亡。生命归零只算战败；只有标为不可逆且经过二次确认的剧情选择才封存为死亡。最终幸存者始终可以隐退。
- 自建角色、鲁迪乌斯、艾莉丝、希露菲、洛琪希与随机开局均可选，保留种族、出身、六维和身份限制。追加属性默认20，可设0–60。高属性不自动赋予无咏唱、斗气或特殊身份。
- 幼年语言、通信约定、被排斥者援助、迷宫研究会影响商店折扣、开局条件、同伴、协作卡牌、警告核验和救援结果。

首次通关 **8–12小时是设计目标**。2.0曾完成全流程引擎重放与浏览器操作验证；2.1已完成自动检查、模拟及出牌特效的本地浏览器视口验收。全站浏览器回归、实体手机与本轮容器运行验收尚未执行。尚未完成8–12小时完整人工试玩，不能将自动测试耗时当作真人时长。没有等待、体力限制或重复刷取门槛。

## 存档与旧版

应用版本2.1.0，剧情版本仍为 `2.0.0`，存储键仍为 `six-faced-world:lives:v2`。客户端兼容读取容器格式2和3，首次有效写入升级为格式3，其他人生和图鉴保留。缺失规则版本的旧档继续2.0原规则，战局与重试保持原费用、牌效和随机数；活动人生位于地区且没有战局、待领取奖励时，可确认更新为2.1规则，保存成功后生效且不能切回。未知规则单独隔离，旧客户端须刷新后继续写入格式3。

每次有效操作成功写入 localStorage 后才推进，刷新可续接当前战局。保存失败暂停所有推进，点击重试保存不会再次出牌或领取奖励。多标签采用排他锁协调，过期动作被拒绝。

出牌特效仅在保存成功后触发，不写入存档、不额外计算战斗或消耗随机数；刷新和其他标签的更新不会重播。连续施放有队列上限，特效不拦截操作且到期自动清理。

每个人生一个自动槽位，完结后只读封存；“人生档案”支持逐档删除，结局图鉴保留。坏槽位与不兼容记录单独标明原因，其他正常记录可继续。无法解析的整个容器保留原始数据并禁止覆盖。

1.0文字版使用原键 `six-faced-world:lives:v1`，保留只读年表、当前正文、逐档删除与图鉴。新版从出生重新开始，不迁移旧属性或进度。

存档只属于当前浏览器和站点来源（协议、域名／IP、端口）。关闭浏览器后可保留，清理站点数据、结束隐私窗口、换设备或地址可能失去记录。容器更新不清除浏览器数据。

## Docker / 1Panel

Linux/AMD64 服务器使用单文件打包命令。本地 Docker 只用于构建及导出镜像，此命令不会启动游戏容器：

```bash
npm run package:amd64
```

执行静态检查、自动测试、生产构建，再生成一个 `release/fatebook-docker-2.1.0-时间戳-amd64.tar.gz`，不生成额外校验文件或发布清单。文件包含完整 Docker 镜像、Nginx、网页和全部内容，服务器导入后无需拉取其他镜像。Docker服务不可用时，也可按[部署说明](deploy/README.md)使用已有完整镜像包离线重建。

在 1Panel 的“容器 → 镜像 → 导入”选择 `.tar.gz`，用导入的新时间戳镜像重建容器，映射 **6657:6657/TCP**，无需挂载目录。访问地址保持不变时，现有浏览器存档可继续使用。

需要多架构归档及校验清单时仍可使用 `npm run package:1panel`。详细配置、域名、更新和回滚见 [部署说明](deploy/README.md)。

## 2.1 规则与界面

攻击明确使用力量、魔力或两者较高值。功能牌强化优先增加抽牌，无抽牌才增加回能；风行改为1费、回能2、抽牌1并消耗，跨流派应变增加消耗。七款同效饰品基础价统一35并合并展示。四类18张预设按当前人物、强化、装备和同伴评分；首胜候选从完整合法池按攻击、守护、功能补缺，胜利时保存，刷新不重选。敌人基础数值、遭遇目标、七章与18结局保持。

界面统一墨绿桌面、暖金动作和纸面卡牌。首页突出活动人生，创建时六维与预设常显，档案按活动、封存和旧版分组，结局正文与百科长文按需展开。手机战斗固定底部战术栏，桌面增加侧栏；先选手牌与目标再确认出牌，行动力不足仍可查看，出牌与结束回合保存成功后才清除选择。

工坊预设先预览，退出组牌提供保存、放弃草稿、继续编辑。购买、强化已单独保存，不随草稿撤销；永久移除收藏需要确认。弹层统一输入层级并恢复焦点。

地区页分为委托、人生选择、地图，一次只展示一个分区；首次开局直接进入基础教学。委托按主线、挑战和已完成筛选，已完成任务仅显示记录，不再提供复习入口；战败仍可免费重试。人生事件显示两句必要背景与选项影响，长文按需展开。年表通过章节选择和记录类型切换，不再嵌套多层折叠。

同名普通／强化卡合为一个条目，用加减数量组牌；加入优先强化副本、取下优先普通副本，原实体 UID 和存档不变。桌面双栏展示牌组与收藏，手机按标签切换，底部保留保存入口。完整96张图鉴支持费用、流派、机制和拥有状态筛选；点卡查看普通／强化对照、实际获取途径与副本维护。其他人物的专属牌可预览，不能编入。

深色面板使用浅色文字，纸面卡牌使用深棕文字。所有卡面共用固定高度与布局槽位：桌面282px、手机270px；名称、费用、全部效果和关键词直接显示，风味说明在详情查看。数量与解锁按钮单独布局，不再撑高卡面。奖励卡支持只读详情。

角色创建、同行援助与全部敌方单位使用动漫立绘，童年和青年按人物年代切换。手机使用缩略图与延迟加载，敌方意图、目标、生命、格挡和牌效直接显示；模态内提供保存失败重试，不用关闭弹窗寻找全局提示。

## 无界面模拟

```bash
npm run balance
npm run balance -- --smoke
```

模拟直接使用正式引擎，旧新规则配对1152次，分别报告入门与启发式政策、逐章回合、损血、旅费与奖励用途。防守构筑在限时救援有超时风险，保留牌疏通也会影响自动政策结果，详见报告；自动完成率不能换算真人时长。
